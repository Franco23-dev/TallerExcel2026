# 📊 Taller Excel 2026

Proyecto desarrollado como práctica de Microsoft Excel aplicando herramientas de organización, análisis y visualización de datos.

## 📌 Descripción

Este proyecto simula el flujo de trabajo utilizado para organizar información comercial, analizar ventas y presentar indicadores mediante un Dashboard interactivo.

El objetivo fue aplicar distintas herramientas de Excel para transformar datos en información útil y fácil de interpretar.

---

## 🚀 Herramientas utilizadas

- Microsoft Excel
- Tablas
- Fórmulas y funciones
- Tablas dinámicas
- Dashboard
- Organización de bases de datos
- Validación y estructuración de información

---

## 📂 Estructura del proyecto

### 📁 Ventas_Brutas

Contiene la base de datos principal utilizada para realizar el análisis.

### 📁 Maestro_Productos

Base con la información de productos utilizada para relacionar datos.

### 📁 Funciones

Aplicación práctica de funciones de Excel para automatizar cálculos y consultas.

### 📁 Tablas_dinamicas

Resumen de información utilizando tablas dinámicas para facilitar el análisis.

### 📁 Dashboard

Panel visual con indicadores que permiten interpretar rápidamente la información obtenida.
