# 📊 Taller Excel 2026

Proyecto desarrollado para poner en práctica herramientas de Microsoft Excel aplicadas a la organización y análisis de datos.

## Objetivo

Diseñar una planilla funcional que permita organizar información de manera clara, automatizar cálculos y facilitar el análisis de datos mediante herramientas propias de Excel.

## Herramientas utilizadas

- Validación de datos
